# 1️⃣ Project Vision
Build a clean, high-performance, and content-first portfolio that emphasizes professional engineering, clean code, and subtle, premium aesthetics.

**Key Principles:**
- **Simplicity:** No gimmicks. Just high-quality content.
- **Performance:** Perfect Lighthouse scores (Speed, Accessibility, SEO).
- **Quality:** Focus on typography, spacing, and smooth transitions.

---

# 2️⃣ Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS + Vanilla CSS for custom typography
- **Components:** Shadcn/UI (for polished, accessible elements)
- **Animations:** Framer Motion (for subtle spring-based movement)
- **Content:** Local JSON files for easy updates
- **Deployment:** Vercel

---

# 3️⃣ Site Structure (Single Page)

1. **Hero:** Name, role, and a one-sentence value proposition.
2. **Selected Work:** 3-4 featured projects with high-quality thumbnails and clear technical descriptions.
3. **Experience:** Minimalist timeline showing career growth and key achievements.
4. **Skills & Expertise:** Modern grid layout of specialized tech (React, RN, AI, etc.).
5. **AI Integration:** A clean, optional toggle to "Chat with my Resume."
6. **Footer:** Contact links and "Built with..." credits.

---

# 4️⃣ Design Palette

- **Primary:** Deep Slate / Charcoal (#0f172a or #000000)
- **Secondary:** Soft Grey / White (#f8fafc or #ffffff)
- **Accent:** A single subtle brand color (e.g., Electric Blue or Emerald) for highlights.
- **Typography:** Sans-serif (Inter / Geist / Outfit) for readability and modern feel.

---

# 5️⃣ Immediate Next Steps

1. **Scaffolding:** `npx create-next-app@latest .`
2. **Configuration:** Setup Tailwind, Shadcn, and global font.
3. **Data Layer:** Create `data/projects.json` and `data/experience.json`.
4. **Implementation:** Build the Hero and Project sections using clean, reusable components.
